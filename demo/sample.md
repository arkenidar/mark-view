# Demo

A self-contained demo of mark-view.

## Features shown here

- Headings, paragraphs, **bold**, *italic*, `inline code`.
- Lists and [links](../README.md).
- A link to the [test-images](../test-images.md) page.
- An anchor link: jump to [the Anchor section](#anchor-section).

```js
function hello(name) {

}
```
